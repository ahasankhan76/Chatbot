# 🤖 AI Chatbot

A full-stack chatbot application built using modern web technologies. This project aims to provide an interactive chat experience with a React-based frontend and Node.js backend.

## 🚀 Project Overview

AI Chatbot is a web-based chatbot project designed to provide users with a simple and interactive conversational interface.

## ⚙️ Installation & Setup

### 1. Clone Repository

```bash
git clone https://github.com/ahasankhan76/Chatbot.git
```

### 2. Setup Backend

```bash
cd Chatbot/backend
npm install
```

Configure your environment variables in a `.env` file.

Start the backend using the command configured in backend/package.json.

### 3. Setup Frontend

Open another terminal:

```bash
cd Chatbot/frontend
npm install
npm run dev
```

Open the local URL displayed in your terminal.

## 🔐 Environment Variables

Keep API keys and secret credentials inside `.env`.

Never upload your `.env` file to GitHub.
